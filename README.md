This is my first attempt at developing an Android app. The ultimate goal is to create a personal Google Maps activity tracker.

If you download the source code and build it yourself, please apply for a Google Maps API key and add it to your local.properties. file with the following definition:

MAPS_API_KEY=\"YOUR_MAPS_API_KEY\"
